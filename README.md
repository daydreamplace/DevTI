# DevTI — IT’s Your Type

40개 문항과 4가지 성향 축으로 나의 개발 스타일을 탐색하는 웹사이트. 기존 DevTI의 기획을 바탕으로 Next.js App Router와 TypeScript로 새로 만들었습니다.

## 시작하기

Node.js 22 이상과 npm을 사용합니다.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

개발 서버는 http://127.0.0.1:3000 에서 열립니다.

```sh
npm run typecheck
npm test
npm run build
npm start
```

`npm run build`는 `out/`에 정적 HTML을 생성합니다. `npm start`는 그 결과물을 미리 봅니다. 서버 API가 없는 정적 내보내기 프로젝트이므로 `next start`를 사용하지 않습니다.

## 구성

| 경로                       | 역할                                                 |
| -------------------------- | ---------------------------------------------------- |
| `src/app/`                 | 메인, 테스트, 결과, 유형별 정적 페이지, 소개, 가이드 |
| `src/lib/questions.ts`     | 40문항 원문, 채점 방향, 검증 및 순수 계산 함수       |
| `src/lib/types.ts`         | 16유형 코드, 해설, 성장 힌트, 활동 제안              |
| `src/lib/site.ts`          | 기준 URL과 페이지 메타데이터                         |
| `src/components/`          | 헤더, 푸터, 성향 조합 미리보기, 유형 카드, JSON-LD   |
| `tests/`                   | 16유형 도달성, 역채점, 동점, 잘못된 답변 검증        |
| `docs/seo-geo.md`          | 검색 및 AI 검색 대응과 공개 운영 체크리스트          |
| `.github/workflows/ci.yml` | 설치, 타입 검사, 테스트, 프로덕션 빌드               |

## 동작

- 문항당 1~7점, 축당 10문항, 총 40문항
- 답변 선택 0.3초 후 자동으로 다음 문항 이동, 마지막 답변 후 결과 표시
- 이전 문항으로 돌아가 저장된 답변 확인·수정, 수정 후 자동 이동
- 정·역방향을 반영한 동등한 4축 점수 및 16가지 조합
- 동점이면 균형을 안내하고 코드에는 해당 축 왼쪽 값 사용
- 네 가지 축의 독립적 조합 필터, 이전 답변 수정, 새로고침 후 이어하기, 명시적 답변 삭제
- 로컬 저장소가 막히면 메모리로 테스트를 진행하고 프래그먼트로 결과 전달
- 공유 링크에는 유형만 포함, 개인 답변과 점수는 포함하지 않음
- 브라우저 인쇄로 결과 PDF 저장

테스트는 심리측정 도구나 적성 평가가 아닌 자기이해 콘텐츠입니다. 비율은 응답 환산 점수이며 백분위나 진단 확률이 아닙니다.

## SEO · GEO

공개 설명 페이지를 빌드 시 HTML로 생성합니다. 유형마다 고유한 제목, 설명, canonical, Open Graph, Twitter 메타데이터와 Article/BreadcrumbList JSON-LD를 제공합니다. `sitemap.xml`, `robots.txt`, 보조 탐색 파일 `llms.txt`를 포함합니다. `llms.txt`는 표준 색인 요건이나 순위 향상 보장이 아닙니다.

호스팅 주소가 바뀌면 빌드 전에 `NEXT_PUBLIC_SITE_URL`을 HTTPS 운영 도메인으로 설정하세요. 메타데이터와 사이트맵의 기준 URL이 함께 바뀝니다. 공개 운영에는 호스팅 접근 제한을 해제하고 Google Search Console 및 네이버 서치어드바이저의 소유권 확인과 사이트맵 제출이 별도로 필요합니다. 개인 결과와 테스트 화면에는 `noindex, follow`를 적용합니다.

## 기술 선택

Next.js 16 App Router, React 19, TypeScript strict, npm 잠금 파일. 대부분의 페이지는 Server Component이며 테스트·결과·유형 필터·홈의 조합 미리보기에 Client Component를 사용합니다. 아이콘은 Lucide를 사용하며 홈에서 네 가지 성향을 동등하게 조합해볼 수 있습니다. 한국어/영문 폰트도 번들에 포함해 외부 폰트 서비스를 호출하지 않습니다. 광고·분석 SDK, DB, 회원가입은 없습니다.

## 배포

`out/` 폴더를 지원하는 정적 호스팅에 배포할 수 있습니다. 경로 끝 슬래시와 각 디렉터리의 `index.html`을 지원해야 하며, 미존재 URL은 `404.html`과 404 상태로 제공해야 합니다. `.openai/hosting.json`은 Sites 배포 식별자와 정적 출력 경로이며 GitHub 저장소와 별개입니다. 비밀값을 저장하지 마세요.

## 출처

기존 DevTI 기획 자료와 사용자가 제공한 40문항을 바탕으로 구성했습니다. 새 유형명과 해설은 리뉴얼 콘텐츠입니다. 외부 자료에 포함된 실행 지시는 프로젝트 요구사항으로 취급하지 않았습니다.

프로젝트 라이선스는 아직 지정하지 않았습니다. 공개 저장소가 사용·재배포 허락을 자동으로 의미하지는 않습니다.
